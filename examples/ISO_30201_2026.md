# Example — ISO 30201:2026

Use Consultant v4.x as the engagement operating system and ISO 30201:2026 as the management-system requirement layer.

Recommended flow:

Opportunity / Client Fit → Readiness → Capability / COI / Engagement Risk → Accept / Decline → Contract → ISO 30201 Requirement Review → Gap → Requirement–Control–Evidence Traceability → HRMS Design → Change & Adoption → Implementation → Evidence → Internal Audit → Management Review → CAR → Quality Gate → Client Acceptance → Benefits → Self-Sufficiency → Closure → Sustainment.

Source classification remains mandatory. ISO requirement text must be validated against an authorized/licensed source before conformity conclusions are issued.
