# Release Checklist

- [ ] Version branch is up to date.
- [ ] Repository Quality Standard completed.
- [ ] Skill version updated.
- [ ] README version updated.
- [ ] `CITATION.cff` version/date updated.
- [ ] Metadata version updated.
- [ ] CHANGELOG updated.
- [ ] Copyright/third-party rights checked.
- [ ] Links and Markdown reviewed.
- [ ] Source classifications reviewed.
- [ ] Professional boundaries/disclaimers reviewed.
- [ ] PR reviewed and explicitly approved.
- [ ] Squash merge used unless a justified alternative is approved.
- [ ] Post-merge files verified on `main`.
- [ ] Release tag and notes created where applicable.
