# Professional Consulting Gates 0–12

| Gate | Name | Core Decision |
|---|---|---|
| 0 | Opportunity / Client Fit | Is this an appropriate client/opportunity? |
| 1 | Ethics / COI / Capability / Risk | Can the assignment be accepted professionally? |
| 2 | Accept / Conditional Accept / Decline | Formal acceptance decision |
| 3 | Contracting / Scope / Acceptance Criteria | Is the work properly contracted? |
| 4 | Diagnosis Complete | Is the problem/current state sufficiently understood? |
| 5 | Client Decision / Solution Approval | Has the client made the required decision? |
| 6 | Implementation Readiness | Are resources, plan, ownership and adoption controls ready? |
| 7 | Evidence / Assurance Readiness | Are controls operating and evidence available? |
| 8 | Deliverable Quality Gate | Is the deliverable professionally defensible? |
| 9 | Client Acceptance | Has formal acceptance occurred? |
| 10 | Benefits / Self-Sufficiency | Can the client sustain the system and own benefits? |
| 11 | Formal Closure | Are contractual, commercial, knowledge and admin obligations closed? |
| 12 | Sustainment Review | Are adoption, benefits, risks and open actions sustained? |
