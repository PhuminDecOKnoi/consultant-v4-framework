# Source Classification

## Mandatory Classes

- `[STD]` Standard-derived
- `[LAW]` Legal / regulatory
- `[CLIENT]` Client-specific / contractual
- `[CONS]` Consultant recommendation / methodology
- `[DATA]` Client / operational data
- `[EVID]` Objective evidence

## Control Rule

Do not present consultant-created scoring systems, maturity models, timelines, KPIs, acceptance criteria, benefits models, readiness scales, fee calculations or implementation methods as ISO or legal requirements unless the cited source explicitly requires them.

## Evidence Principle

Evidence should be sufficient, relevant, reliable and traceable to the requirement/control being evaluated. Conclusions should not exceed what the available evidence supports.
