# Context

## Purpose

This repository provides a reusable operating framework for professional consulting assignments, especially management-system implementation and transformation.

## Intended assignment types

- ISO and other management systems;
- HR and workforce-management systems;
- labour and compliance governance;
- audit and assurance readiness;
- knowledge management;
- risk and governance;
- ESG and responsible-business systems;
- process, data and organizational transformation.

## Core boundary

The framework governs **how consulting work is qualified, contracted, delivered, assured, accepted, valued and closed**. The underlying requirement layer remains assignment-specific and must come from authorized standards, laws, contracts and client requirements.

## Evidence boundary

Professional conclusions should be evidence-based. Missing evidence must not be silently replaced with assumptions.
