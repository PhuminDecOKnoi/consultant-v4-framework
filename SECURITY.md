# Security Policy

## Scope

This repository contains consulting methodology, AI-agent instructions, governance material and templates. Security concerns include both technical repository security and professional information-security risks.

## Do not commit

- API keys, tokens, passwords or credentials;
- client-confidential information;
- personal data or restricted employee data;
- client contracts unless explicitly sanitized and authorized;
- proprietary standards text that cannot be redistributed;
- confidential audit evidence;
- privileged legal material;
- production system secrets or internal network details.

## Reporting a security concern

Do not publish sensitive security details in a public issue. Contact the repository owner through an appropriate private channel available on the owner's GitHub profile.

## Professional information controls

Before publishing an example, template or case study:

1. remove client-identifying data;
2. confirm confidentiality and IP permissions;
3. classify source material;
4. confirm no third-party copyrighted standard text is reproduced beyond permitted limits;
5. check that examples cannot be mistaken for binding law, certification criteria or ISO requirements.
