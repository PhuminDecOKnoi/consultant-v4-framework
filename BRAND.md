# Brand & Naming Standard

## Canonical name

**Consultant v4.x — Professional Consultancy Management System & Operating Framework**

## Skill command

`/SKILL Consultant`

Default release line: **v4.x**.

## Repository slug

`consultant-v4-framework`

## Short description

A professional consultancy governance, engagement, delivery, assurance, value-realization and knowledge-management framework for management-system and transformation consulting.

## Naming rules

- Use **Consultant v4.x** for the release family.
- Use **Consultant v4.0** when referring to the initial major release.
- Use **Professional Consultancy Management System & Operating Framework** as the formal subtitle.
- Use lowercase kebab-case for new folders and filenames unless a community-standard filename requires uppercase, for example `README.md`, `SECURITY.md`, or `CITATION.cff`.
- Do not imply affiliation, endorsement, certification or ownership by ISO or any standards body.
