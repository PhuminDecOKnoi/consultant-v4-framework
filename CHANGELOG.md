# Changelog

All notable changes to this repository are documented here.

## [4.0.0] — 2026-08-08

### Added

- Professional Consultancy Management System with four-layer architecture.
- Professional Consulting Gates 0–12.
- Client/sponsor readiness, capability fit, COI, engagement risk and assignment acceptance controls.
- Effort/fee estimation and engagement economics.
- Requirement–Control–Evidence traceability.
- Deliverable quality gate, senior/independent review, self-sufficiency, knowledge assets and CPD.
- Source classification: `[STD] [LAW] [CLIENT] [CONS] [DATA] [EVID]`.
- Public GitHub repository governance aligned to `/SKILL std GitHub`.
- MIT license, citation metadata, brand guidance, security, contribution, support and conduct files.
- CODEOWNERS, PR template and structured issue forms.
- Repository quality, versioning, change-control and release checklists.
- AI/search discovery metadata via `llms.txt`, `repository.json` and `skill-registry.yaml`.
- Standard skill-library path at `skills/consultant-v4/SKILL.md`.

### Governance

- `main` is the stable release branch.
- Normal upgrades use `version-X.Y[-scope]` branches.
- Conventional Commits and QA-before-PR are required by repository policy.
- Squash merge is the preferred merge strategy after explicit approval.

### Copyright boundary

- Full copyrighted ISO standards text is not included.
- Consultant-created methodology remains explicitly separate from standard-derived requirements.
